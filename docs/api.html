POST /auth/register Create New Account
Public

Registers a new customer, shopkeeper, or delivery agent. Returns JWT auth credentials upon creation.

Request Body (JSON)
Application/json
{
  "name": "Sayan Pandit",
  "email": "sayan@example.com",
  "password": "StrongPassword123!",
  "role": "customer" // "customer" | "shopkeeper" | "delivery"
}
Response (201 Created)
Response Body
{
  "statusCode": 201,
  "accessToken": "eyJhbGciOiJIUzI1NiIsIn...",
  "user": {
    "id": "674128f...",
    "name": "Sayan Pandit",
    "email": "sayan@example.com",
    "role": "customer"
  }
}

POST /auth/forgot-password Request 6-Digit Password Reset OTP
Public

Generates a cryptographically secure 6-digit numeric OTP with 10-minute expiry and sends via Titan/Resend luxury HTML email template.

Request Body
Application/json
{
  "email": "customer@vytra.co.in"
}
Response (200 OK)
Response Body
{
  "success": true,
  "message": "Reset verification code sent to your email"
}
POST /auth/reset-password Confirm OTP & Update Password
Public

}
Response (200 OK)
Response Body
{

  "message": "Password updated successfully. Please log in with your new password."
}

POST /cart/items Atomic Add / Increment Cart Item
Bearer JWT

Safely adds an item to cart or increments quantity using atomic MongoDB $inc mutex, preventing race condition over-ordering.

Request Body
Application/json
{
  "productId": "6741a2e4...",
  "quantity": 1
}
Response (200 OK)
Response Body
{
  "success": true,
  "cart": {
    "totalItems": 3,
    "totalAmount": 840
  }
}
PATCH /cart/items/:productId Update Item Quantity
Bearer JWT

Updates item quantity directly. If quantity is 0, item is automatically pruned from the cart.

URL Parameters
ParameterTypeDescription
productId *ObjectIdTarget product ID
Request Body
Application/json
{
  "quantity": 3
}

POST /orders Checkout & Place Order
Bearer JWT

Validates stock with atomic decrement, empties cart, and spawns new order in pending status. Triggers HyperOS live notification pipeline.

Request Body
Application/json
{
  "shopId": "67419a...",
  "items": [
    { "productId": "6741a2...", "quantity": 2 }
  ],

    "street": "12/A College Road",
    "city": "Kolkata",
    "postalCode": "700001",
    "coordinates": [88.3639, 22.5726]
  },

POST /orders/:id/cancel Cancel Order & Auto-Restore Inventory
Bearer JWT

Cancels an order if it is in pending or confirmed state. Once an order is packed or out_for_delivery, cancellation is strictly rejected with 409 Conflict. Restores product inventory via $inc.

Response (200 OK)
Response Body
{
  "success": true,
  "message": "Order #VY-8921 cancelled successfully. Stock has been restored.",
  "order": {
    "_id": "6741d4...",
    "status": "cancelled",
    "cancellationTimestamp": "2026-10-02T01:30:00.000Z"
  }
}
