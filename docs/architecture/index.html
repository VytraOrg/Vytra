2. Core Architectural Pillars

⚡

Atomic Inventory Mutex

Cart increments, order checkouts, and cancellations use atomic MongoDB $inc operations with strict inventory bounds checking, completely eliminating race conditions.

🛡️

Dual-Layer Cache Resilience

Cloud Redis TLS with an automatic in-memory RAM fallback ensures that if cloud cache fails, the API serves recommendations and cached products without downtime.

✨

Hybrid Recommendation Engine

A 3-tier pipeline combining historical order co-occurrence aggregation, category complement matrices, and store bestsellers with 600s cache TTL.

🔔

HyperOS Live Tracking

Real-time delivery progress updates integrated with Xiaomi HyperOS promoted notifications and an in-app dynamic island widget aligned with phone camera punch-holes.

4. Order Lifecycle & Inventory Integrity

State Machine & Cancellation Rules

[ Placed ] ──────➔ [ Processing ] ──────➔ [ Dispatched ] ──────➔ [ Delivered ] │ │ │ │ ▼ (Customer Can Cancel)│ ▼ ▼ [ Cancelled ] ◄───────────┘ (Locked - Delivery Agent in route) │ ▼ Stock Restored: MongoDB $inc: { stockQuantity: +quantity }

Once an order transitions to Dispatched, Shipped, or Delivered, cancellation is strictly locked on both frontend and backend to protect merchant economics and live driver dispatch.
